# MapGen landscape assets

These runtime assets are copied from the repository-local MapGen visual baseline
at `/Users/matt_wittlief_home/lotm-mapgen/public/assets` for the in-process
CourtOS renderer. They are used only as visual materials and vegetation art;
canonical manor existence, condition, improvement status, and placement scope
continue to come from the admitted CourtOS read model and `manor_fabric` facts.

Copied families:

- `materials/`: Pearwick estate terrain-material textures.
- `vegetation/`: oak, orchard, hedgerow, and groundcover sprite variants.

No asset in this directory is runtime truth, and no coordinate or facility
existence is inferred from the artwork.
