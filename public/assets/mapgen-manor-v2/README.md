# Merecross manor-pilot asset package v2

This directory is generated by `scripts/buildManorPilotAssetManifestV2.mjs`
from the seven approved 3×3 alpha atlases in `manor-pilot-v1`.
The source compositions do not consistently respect exact mathematical thirds,
so extraction locates transparent horizontal and per-row vertical gutters before
measuring and cropping each semantic cell.

## Contents

- `asset-manifest-v2.json`: crop, alpha, ground-anchor, footprint, and safe
  render-scale metadata for all 63 cells.
- `qa-report-v2.json`: deterministic round-trip and alpha validation.
- `sprites/<atlas>/`: one tightly cropped RGBA PNG per atlas cell.

## Grounding contract

Use the individual sprite PNG, not an atlas UV crop. Set the sprite center from
`groundAnchor.normalizedSpriteCenter`, then position that anchor on a locally
fitted terrain plane. The anchor is measured from the lowest occupied alpha row,
and its horizontal position is the robust center of the bottom alpha footprint.
Do not add a generic half-height or hand-tuned vertical offset.

```js
const asset = manifest.assets.find((entry) => entry.id === assetId);
const texture = await textureLoader.loadAsync(asset.output.png);
const sprite = new THREE.Sprite(new THREE.SpriteMaterial({ map: texture, transparent: true }));
sprite.center.set(
  asset.groundAnchor.normalizedSpriteCenter.x,
  asset.groundAnchor.normalizedSpriteCenter.yFromBottom,
);
sprite.scale.set(
  asset.renderScale.recommendedWidthWorldUnits,
  asset.renderScale.recommendedHeightWorldUnits,
  1,
);
sprite.position.set(worldX, fittedTerrainHeightAtAnchor + 0.02, worldZ);
```

Billboard size should start from `renderScale.recommendedHeightWorldUnits` and
remain inside `renderScale.safeHeightWorldUnits`. Width follows the native
cropped aspect ratio. Large structures should receive a graded terrain terrace
matching their measured footprint rather than being balanced on one height
sample.
