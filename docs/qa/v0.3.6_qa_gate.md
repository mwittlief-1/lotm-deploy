# v0.3.6 QA Gate Evidence

The accepted branch-wide QA evidence for the v0.3.6 tooling lane is `qa_artifacts/v0.3.6_qa.json`.

`npm run qa` writes version-scoped evidence first:

- summary: `qa_artifacts/v0.3.6_qa.json`
- Vitest JSON: `qa_artifacts/v0.3.6_vitest.json`
- UAT gate JSON: `qa_artifacts/v0.3.6_uat_gate.json`

The legacy paths `qa_artifacts/vitest.json` and `qa_artifacts/uat_gate.json` are refreshed as compatibility mirrors only. Release-close handoff should point at the version-scoped summary path above so stale leftovers cannot be confused with current gate truth.

This QA evidence is paired with the v0.3.6 preflight baseline policy in `docs/qa/v0.3.6_preflight_baseline_contract.md`.
