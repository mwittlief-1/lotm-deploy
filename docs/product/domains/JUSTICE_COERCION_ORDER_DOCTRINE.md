## Doctrine

Justice and coercion create moral-strategic tension. Lawful coercion, unlawful violence, accusation, punishment, pardon, local order, fear, legitimacy, and Church/liege perception should interact.

Law / Justice / Accusation is a domain, not a new core action family by itself.

## Action-family mapping

- accuse → Claim / Contest / Enforce Right;
- investigate crime → Investigate / Verify / Monitor;
- hold hearing → Support / Oppose / Mediate / Adjudicate;
- punish offender → Suppress / Appease / Negotiate Disorder;
- appeal judgment → Claim / Contest / Enforce Right;
- pardon → Petition / Grant / Recognize.
