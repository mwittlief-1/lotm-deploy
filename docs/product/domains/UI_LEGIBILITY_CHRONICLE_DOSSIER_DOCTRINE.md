## Core doctrine

Player-facing surfaces are read models/projections. They must not become source truth.

The UI should make the world legible without exposing raw internals or implying omniscience.

SP-010 ratifies confidence/provenance vocabulary for planning, but it does not authorize UI integration, schema promotion, or hidden-truth exposure.

## Primary surfaces

Likely top-level surfaces:

- Turn / Briefing / Agenda;
- House;
- Estate / Manor;
- Realm / Court;
- Dossiers;
- Ledger;
- Chronicle.

## Presentation stack

For major outcomes:

1. Narrative synthesis.
2. Structured effects.
3. Receipts/provenance.
4. Inspectable “why?” path.

## Chronicle

The Chronicle preserves durable structural events and memory, not every minor internal tick.

Chronicle candidates:

- succession;
- marriage;
- birth/death of major figures;
- major obligation conflict;
- land transfer;
- serious incident/crisis;
- house status change;
- church/court milestone;
- ruin/recovery event.

## Stop rules

Codex must not integrate UI around proof scaffolds or treat UI summaries as source truth.
