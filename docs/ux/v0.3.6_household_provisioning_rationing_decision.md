# v0.3.6 Household Provisioning Rationing Decision

## Decision

Rationing is **not editable in v0.3.6**.

The UI should restore and preserve the detailed household consumption/provisioning table, but it must remain read-only against sim state. The current accepted contracts expose effective ration level, requested food/meat, allocated food/meat, shortfall, lodging, stipend basis, and carry-forward state through `court_provisioning_view_v1` and `court_stipend_registry_v1`. They do not expose a canonical player decision payload for changing ration levels.

## Player Path

- `HouseholdPanel` shows the detailed household consumption/provisioning table inline with the household card.
- `CourtProvisioningPanel` shows the same combined table in the provisioning sheet, alongside the older allocation, overrides, and stipend tables.
- Both surfaces state that rationing is read-only for v0.3.6 and that future ration controls must route through an owned decision flow before mutating sim state.
