# v0.3.4 Playtest Ops Implementation Notes

**Scope:** summarize what shipped for the `V03-R4-003` playtest-ops pass, record the live gameplay-shell hooks that now support packet assembly, and leave one hardening handoff for later `v0.3` final review.

## 1. Shipped packet and reporting contract

The `v0.3.4` playtest-ops pass now has one stable contract across UI, docs, and checked-in QA templates:

- packet seam: `src/ui/playtestOpsPacket.ts`
- export helper seam: `src/ui/playtestOpsExport.ts`
- packet convention doc: `docs/ux/v0.3.4_playtest_receipt_bundle_conventions.md`
- reporting expectations doc: `docs/ux/v0.3.4_playtest_reporting_expectations.md`
- seed pack: `qa_artifacts/playtest_ops/v0.3.4/receipt_bundle_seed_pack.json`
- bug template: `qa_artifacts/playtest_ops/v0.3.4/bug_report_template.md`
- KPI placeholder template: `qa_artifacts/playtest_ops/v0.3.4/kpi_placeholders.json`

Together they define:

- the canonical packet name and capture root
- the scenario list for playtest packet review
- which artifacts are true UI exports versus manual notes
- the stable filenames for KPI snapshots and per-issue packet reports

## 2. Live UI hooks

The gameplay shell now exposes the packet workflow in the mainline UI instead of treating it as a debug-only habit:

- `DecisionsPanel.tsx` now exposes `Open Run Log` next to the two export buttons and explains the exact filenames a tester should save for the packet.
- `RunLogScreen.tsx` now labels itself as the raw-evidence home and points back to the packet filenames and reporting files.
- `PlayScreen.tsx` keeps the debug accordion as a fallback raw-evidence path, but now explains that the packet review flow starts from the main gameplay shell.

That does not create a one-click bundle exporter. It does make the current manual packet flow visible where testers already act.

## 3. Hardening handoff

The `V03-R4-003` epic is now ready for later `v0.3` final hardening with these known limits:

- packet assembly is still manual
- receipt evidence is still notes-based rather than exported directly
- KPI values are placeholders, not automated measurements

If later hardening work changes filenames, packet roots, or reporting fields, it should update the seams and templates listed above together so the playtest flow does not drift back into audit-by-search.
