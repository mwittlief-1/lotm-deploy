move evidence emission closer to the owned domain seams, and expose

## Snapshot and debug output gaps

1. `boundedSnapshot(...)` exposes hidden `beliefs`, but it does not expose a corresponding hidden evidence packet or any per-subject belief summary. Current AI debug requires reconstructing meaning from phase results and belief rows separately.
2. `PhaseResultV0.evidence_events_v0` is available for the current turn, but it is a phase-local transport surface, not a stable AI debug contract. There is no single read-only surface for "current evidence", "stored beliefs", and "neutral policy inputs" together.
3. Grant and succession seams already use hidden bounded-snapshot surfaces for other domains. AI does not yet have an equivalent hidden debug surface beyond raw `beliefs`.
4. The current evidence schema is detail-string oriented. That is sufficient for rails-only logging, but it leaves obligations and grants unable to surface deterministic machine-readable metadata without another schema step.

## Findings

1. The baseline AI rail is real and working: evidence adapters, belief storage, and neutral hook scoring already exist and are test-backed.
2. Marriage has the best current AI coverage because preview offers already emit subject-scoped evidence, but marriage resolution still falls back to generic note evidence.
3. Obligations are the largest emitter gap. The domain already computes settlement, carry, and enforcement facts, but none of those facts currently enter the AI rail as typed evidence with liege or clergy subject binding.
4. Grant generation and resolution already exist as deterministic read surfaces, but current AI capture is still generic prospects logging. Grant-specific provenance and blocker data are not preserved in evidence.
5. The present rail is still orchestrator-centric. `turn.ts` owns the capture pass, so domain seams do not yet author their own evidence in the place where counterparty ids, source entries, and rule ids are already known.
6. Snapshot/debug visibility is only half-finished: hidden `beliefs` exists, but evidence and neutral policy explanations do not yet have a canonical read-only debug packet.

## Task-to-task handoff

- `V03-R3-006-T03` should add deterministic typed evidence emission at the owned domain seams, starting with marriage resolution, obligation settlement/enforcement, and grant flows. The goal is to stop depending on generic note synthesis where structured facts already exist.
- `V03-R3-006-T04` should expose read-only debug outputs for beliefs, current evidence, and neutral policy hooks so later UI/content work can inspect the rails without changing gameplay authority.
- `V03-R3-006-T05` can then refresh the public AI rail docs once the payload, emitters, and debug surfaces are stable.
