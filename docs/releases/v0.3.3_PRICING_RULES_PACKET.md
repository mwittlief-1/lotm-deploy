**Last Updated:** 2026-04-04
**Owner:** Economy / Fiscal lane
**Reference Packet:** `docs/releases/v0.3_FISCAL_SPINE_PACKET.md`

This document is the authoritative `v0.3.3` pricing closeout for `V03-R3-004`. It records the fixed-price rules, the regression anchors that lock them, and the handoff boundary for later balance-hook work.

## Locked baseline
- Pricing remains deterministic and constant-driven in `v0.3.3`.
- There is still no market simulation in scope for `v0.3`.
- The economy-owned pricing contract is now the canonical source for read-only price references.
- `TurnReport.market` still exists for live phase output, but UI-facing price-reference presentation should read from the extracted pricing view instead of recomputing ratios in the panel layer.

## Fixed sell rules
- Food-store sale quoting uses integer-ratio math only:
  - `quoted_coin = floor(sold_units * quote_amount / base_amount)`
- Food-store sell cap remains population-scaled and fixed:
  - `sell_cap_units = floor(population * BUSHELS_PER_PERSON_PER_YEAR)`
  - With the current `BUSHELS_PER_PERSON_PER_YEAR = 12`, a population of `20` yields a cap of `240`.
- Allowed sale units clamp in this order:
  - requested units
  - fixed sell cap
  - available `food_stores`
- Placeholder meat and labor references are catalog entries only. They do not authorize live runtime sale or wage flows in `v0.3.3`.

## Read-only transport rules
- The experience layer snapshots `economy_pricing_view_v1` into bounded snapshot surfaces.
- The pricing view carries:
  - canonical reference order
  - typed price references
  - the read-only `food_stores_sell_action` summary for current population and inventory
- UI surfaces should read that derived pricing view or the normalized pricing surface built from it.
- UI code should not recreate quote ratios, cap math, or placeholder ordering ad hoc.

## Handoff to balance-hook work
- Balance-hook work should tune pricing constants by editing the economy-owned price contract rather than introducing new UI or phase-local ratio math.
