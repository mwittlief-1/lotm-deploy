# v0.3.3 Pricing Surface Audit (V03-R3-004-T01)

**Last Updated:** 2026-03-31
**Owner:** Economy / Fiscal lane
**Reference Packet:** `docs/releases/v0.3_FISCAL_SPINE_PACKET.md`

This audit inventories the current price, sell-cap, and trade-placeholder surfaces that exist before `V03-R3-004-T02` introduces a typed pricing contract. It is descriptive only. No live pricing behavior changes are made here.

## Scope lock carried into pricing
- `v0.3.3` pricing remains constant-driven and deterministic.
- There is no market simulation in scope for `v0.3`.
- The fiscal asset baseline handed forward from `v0.3.0` remains `coin`, `food_stores`, and `meat_stores`.
- Current runtime pricing still lives in the phase layer; this audit maps those surfaces so the follow-on tasks can extract them safely.

| Event trade modifiers | `src/content/events.ts` | `market_price_mult` and `sell_cap_mult` mods from `evt_market_glut`, `evt_market_shortage`, `evt_muddy_roads`, `evt_clear_roads` | Current trade tuning arrives as generic per-turn flag mods, not typed pricing adjustments. |

## Findings
1. The live price and sell-cap mechanics are deterministic, but they are still owned by `src/sim/phases/phase_consumption.ts`, not by an economy pricing seam.
2. `TurnReport.market` is the only runtime transport surface for price data today. UI components are already read-only consumers of that shape.
3. Current pricing is grain-only. There is no typed price surface for `food_stores` versus `meat_stores`, and there are no labor-price placeholders yet.
4. Current trade tuning mixes global constants, improvement modifiers, and generic event flag mods. Those knobs are real surfaces, but they are not gathered into one versioned pricing contract.
5. Canonical market-sale receipt taxonomy exists in tests and fixtures, but the live sell flow does not emit those receipt rows yet.
6. `service_placeholder` belongs to fiscal settlement scaffolding, not pricing. The minimal pricing work should not reuse it as a stand-in for price references.

## Gaps against minimal pricing scope
| Minimal pricing need | Current gap |
| --- | --- |
| Typed deterministic price table | No economy-owned table or identifier set exists for grain, meat, or labor placeholders. |
| Versioned price reference contract | `TurnReport.market` is an unversioned shape, and no dedicated snapshot/reference object exists. |
| Economy-owned lookup seam | All active pricing math still lives in `phase_consumption`, outside the economy domain. |
| Constant-driven behavior without RNG drift | Live price/cap values still depend on `market` RNG output and per-turn event mods. |
| Canonical sale receipt ownership | The live sell phase does not write ordered ledger receipts for market sale outflow/inflow. |
| UI/read-model stability | UI surfaces consume raw report fields directly and have no read-only price-reference abstraction yet. |
