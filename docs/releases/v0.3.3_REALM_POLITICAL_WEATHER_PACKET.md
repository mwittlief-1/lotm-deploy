## Locked baseline

- `v0.3.3` keeps realm pressure descriptive and read-only.
- Crown, magnate, and church pressure all ship as scaffolding surfaces
  only; they do not activate new sim mechanics.
- The canonical live contracts are:
  - `realm_pressure_registry_v1`
  - `political_weather_v1`
  - `political_weather_content_hooks_v1`
- Snapshot/export consumers should read the extracted political-weather
  surfaces instead of inferring politics from arrears, unrest, or house
  summaries ad hoc.

## Deterministic fixture anchors

The political-weather scaffold now has explicit review artifacts:

- `qa_artifacts/realm_pressure/realm_pressure_registry_v0.3.3.json`
- `qa_artifacts/realm_pressure/political_weather_v0.3.3.json`
- `qa_artifacts/realm_pressure/political_weather_content_hooks_v0.3.3.json`
- `tests/sim/political_weather_fixtures.test.ts`

These fixtures intentionally use a compact synthetic state rather than a
full seeded run so the review packet stays bounded and readable while
still locking:

- actor ordering
- seeded latent-pressure values
- source surface IDs and summaries
- summary-line wording
- content-hook banding and highest-pressure selection

## Read-only transport boundary

- `political_weather_v1` remains the canonical bounded snapshot field
  for downstream UI, logging, and reporting consumers.
- `political_weather_content_hooks_v1` is derived from the same
  registry-backed weather object and should stay read-only until a later
  activation tranche explicitly widens scope.
- The fixture packet complements, but does not replace, the bounded
  snapshot regression coverage added in `V03-R3-005-T04`.

## Activation handoff

- Later realm-pressure activation work should reuse the existing actor
  keys, schema versions, and summary ordering instead of replacing the
  scaffold with new ad hoc structures.
- If future work changes latent-pressure math intentionally, it should
  update the fixture packet and release docs together so the review
  delta stays legible.
- Church pressure remains intentionally split between clergy personhood
  and parish visibility until later church/institution tasks close that
  seam.
