# V03-R5-009-T02 - Canonical preset application seam

## Summary

Accepted the integrator-owned preset seam on `codex/v0.3-refactor-kickoff`.
New runs now flow through one canonical init payload before `createNewRun()`
runs worldgen, normalization, and migrations. `applyPlayabilityPreset()`
mutates only that init payload, and `createNewRun()` still produces the same
sim state for a given seed unless provenance fields intentionally differ.
